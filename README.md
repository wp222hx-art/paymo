# 星光云 · 会花钱，也会轻松清偿

用户在平台买日常用品 → 平台获得返佣 → **返佣 × 返还倍率 = 清偿金** → 一键清偿银行账单 → 偿清后银行出具《偿清证明》与回函。

| 目录 | 说明 |
| --- | --- |
| `lib/` | 用户端 App（Flutter，Web / Android）。C 端主界面在 `lib/ui/mall/` |
| `server/` | 后端 API（Node.js 22.5+ / Express / 内置 SQLite），同时托管 App、后台与媒体 |
| `admin/` | 运营后台（Vue 3 + Element Plus） |
| `server/public/media/` | 生成的指引视频（`video/`）与视觉素材（`img/`，WebP） |
| `media-src/` | 视频/图片的生成脚本、提示词与解说稿（可重新生成） |

## 部署

```bash
FLUTTER=/path/to/flutter ./build_all.sh
cd server && npm start
```

- 用户端：`http://<host>:8080/`（演示：`/?as=U1001&guide=0` 林晓明；`U1002` 苏雨桐已有一笔可偿清账单）
- 运营后台：`http://<host>:8080/admin/`（首次启动 `admin / admin123`）
- 数据库：`server/data/xinguang.db`；`npm run reset` 清空重建

环境变量：`PORT`、`HOST`、`DATA_DIR`、`ADMIN_PASSWORD`、`JWT_SECRET`、`CORS_ORIGIN`、`DEMO_MODE=0`（关闭演示登录/模拟支付/模拟充值/演示验证码）、`DEMO_SMS_CODE`（默认 123456）。

## 用语

| 界面用语 | 含义 |
| --- | --- |
| 清偿金 | 购物返还，1 元可核减 1 元银行账单 |
| 待清偿账单 | 从合作银行导入的信用卡 / 贷款账单 |
| 一键清偿 | 用清偿金向银行提交清偿 |
| 偿清 / 偿清证明 | 账单余额归零；银行出具电子证明 + 偿清确认函 |
| 银行回函 | 接入确认函 / 清偿回执 / 偿清确认函 |

## 业务流程

1. **查账单**：输入手机号 + 短信验证 + 授权书 → 模拟银行网关返回名下账单（`server/src/services/bank.js`，同一手机号结果稳定）→ 授权接入，银行发《账单接入确认函》。
2. **购物**：9 大类 / 30 小类 / 122 个真实品牌 SKU（`server/src/catalog.js`）。清偿金 = 售价 × 返佣率 × min(大类基础倍率 + 信用加成, 全局上限)。
3. **收货 → 保障期 → 到账**：确认收货后 7 天售后保障期，期满自动到账；退款则失效。
4. **一键清偿**：银行受理 → 资金划转（金额 = 返佣背书）→ 核减（面值与背书的差额为银行让利），每步发回执；余额归零自动签发偿清证明，信用分 +15。
5. 所有资金变动写复式分录，后台「财务分录」实时校验借贷平衡。

## 微劳动（融合原平台任务体系）

- 角色：**用户**接单；**商家**发任务、托管押金、验收；**风控/运营**处理申诉仲裁、提现审核、内容审核、风险案件；**合作银行专员**只看本行清偿单（受理 / 核减）。
- 流程：商家发布（押金 = 报酬 × 名额，平台托管；含敏感词进人工审核）→ 用户接单（实名等级 / 信用分门槛，同时最多 5 单）→ 提交交付物 → **AI 原创初审**（<60 分可改后重交，最多 3 次）→ 商家 72 小时内验收（超时自动通过；驳回须写原因）→ 用户可申诉、平台仲裁 → **结算分账**：平台服务费 10%，其余按商家设定比例拆成「可提现现金」+「清偿金」（清偿金享信用分加成）。
- 钱包与提现：实名 L1 手机 → L2 实名 → L3 活体 → L4 银行卡 + 支付密码；风控规则（大额、高频、新绑卡、提现超收入）命中则转人工复核或拦截，≤500 元且无风险时自动到账。
- 社区：发帖需实名，命中引流 / 征信修复话术直接拦截，敏感话题转人工；内容激励按互动量计算，同样拆成现金 + 清偿金。
- AI 助手：清偿规划师 / 任务匹配 / 创作助手。设置 `AI_API_KEY`（可选 `AI_BASE_URL`、`AI_MODEL`，OpenAI 兼容接口）接入大模型，未设置时使用内置规则引擎；含提示词注入防护。
- 登录：在登录页选择身份后点「登录」即可（林晓明、苏雨桐为用户，星辰品牌、云栖餐饮为商家，马上消费金融、招商银行为银行专员，陈锐为风控）。「我的」页右上角可随时切换身份。苏雨桐支付密码 `135790`。
- 旧版 mock 前端（负债人 / DP 等用语）已整体下线，移至 `../paymo_legacy_ui/` 备查。

## 视频与视觉

- 13 条竖版指引视频（总介绍 + 清偿 9 个环节 + 微劳动 3 个环节），由 Seedance 2.0 生成画面，统一主角形象；中文解说配音 + 烧录字幕，H.264 / CRF 27，约 1~2 MB/条，`faststart` 边下边播。
- 83 张视觉素材由 Seedream 生成，压缩为 WebP 两档（主图 + `@s` 320px 缩略图），共约 3.2 MB；`/media` 设置 30 天强缓存。
- 每个功能页都嵌入对应环节的「看视频」指引条；首页、「我的 - 视频指引」可连续观看。
